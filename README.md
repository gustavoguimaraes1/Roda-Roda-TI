## 📺 Sobre o programa

O **Roda Roda TI** transforma programação competitiva em um verdadeiro programa de auditório.

A dinâmica mistura:

```text
🎡 Sorte
   ↓
💻 Linguagem
   ↓
🧩 Desafio Beecrowd
   ↓
⌨️ Código
   ↓
✅ Accepted
      ou
💀 Segmentation Fault
```

O participante gira a roleta, recebe uma linguagem aleatória e precisa resolver um desafio do **Beecrowd** utilizando exatamente a tecnologia sorteada.

> **Girou. Caiu. Programou.**

---

## 🎮 Como funciona

| Etapa            | O que acontece                                   |
| ---------------- | ------------------------------------------------ |
| 🎡 **Roleta**    | Uma linguagem é sorteada                         |
| 🧩 **Desafio**   | Um problema do Beecrowd é escolhido              |
| ⏱️ **Tempo**     | O participante precisa resolver dentro do limite |
| 💻 **Código**    | A solução deve usar a linguagem sorteada         |
| 🚀 **Envio**     | O código é submetido                             |
| 🏆 **Resultado** | O objetivo é conseguir `Accepted`                |

* strings;

* matrizes;
* estruturas de dados;
* recursão;
